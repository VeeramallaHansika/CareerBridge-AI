# CareerBridge-AI
Skill-Gap Mentor &amp; Career-Readiness Assistant for Semi-Urban Women Graduates.
CareerBridge AI is a document-grounded AI career mentor for semi-urban female undergraduate and diploma graduates (supporting SDGs 4, 5, and 8). Using tools like NotebookLM and Gemini, it checks skill gaps, helps improve resumes, and builds career-readiness roadmaps for entry-level roles.
